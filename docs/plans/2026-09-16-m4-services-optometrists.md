# M4 Services and Optometrists Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Services and Optometrists "coming soon" stubs with real pages: a services list, a detail page per service (statically exported, 404 for unknown slugs), and an optometrist directory with client-side branch filtering.

**Architecture:** Server Components read content through `src/lib/content.ts`. Dynamic service routes are pre-rendered with `generateStaticParams()` and `dynamicParams = false`, so the export contains one HTML file per service and nothing resolves at request time. Each async page is a thin wrapper that awaits `params` and delegates to a synchronous presentational component, which is what the unit tests render. Only the optometrist filter is a client island.

**Tech Stack:** unchanged from M1–M3 (Next.js 16.3.5 static export, Tailwind v4, shadcn/ui, Vitest + RTL, Playwright + axe).

**Spec:** [docs/specs/2026-09-15-clearview-optical-design.md](../specs/2026-09-15-clearview-optical-design.md) — milestone M4 (§11), page composition (§6), content model (§5), static-export constraints (§5).

**Plan 3 of the milestone series** (M0; M1–M3; this). M5 (Branches) and M6 (About/FAQ/Contact/Privacy) follow.

## Preconditions

- M3 is committed (HEAD `a21ca67` or later) and `git status` is clean.
- The owner's main session has run the CLAUDE.md security audit for this session and approved it. Subagents skip the audit.

## Global Constraints

- Next.js 16.3.5, `output: 'export'`: read `node_modules/next/dist/docs/` before using a Next API. No server features.
- `PageProps<'/route'>` and `LayoutProps<'/route'>` are global helpers generated by `next typegen`; `params` is a Promise and must be awaited.
- Every dynamic route exports `generateStaticParams()` and `export const dynamicParams = false`.
- Links only to routes that exist. Branch detail pages arrive in M5, so anything about a branch links to `/branches` for now.
- Application code under `src/`; pages read content only through `src/lib/content.ts`; `src/lib/` has no React imports.
- Design tokens only (cream `#FAF7F2`, sand `#EFE8DD`, teal `#0F4C4A`, teal-soft `#2E7270`, amber `#E8A95B`, ink `#1F2A2A`, `rounded-card`); amber is a fill, never small text on cream.
- Accessibility: one `<h1>` per page, no skipped heading levels, visible focus (`focus-visible:outline-2 focus-visible:outline-offset-2` with `outline-primary` on light backgrounds), 44 px targets, alt text, no horizontal scroll at 320–1920 px.
- Motion: one signature animation per page (the Hero on Home only); elsewhere `Reveal` (CSS scroll-driven) or nothing. No new JS animation library use.
- Tests: unit tests render synchronous components; async pages are covered by E2E. Every new route joins the E2E route list, including the reduced-motion axe pass that is the only check that sees `.reveal` content.
- React Compiler lint rules apply: no `setState` in effects, no impure calls in render, no ref reads during render.
- **Owner workflow:** single `main` branch. Agents never run `git add`, `git commit`, `git push` or create branches; leave changes in the working tree. Execution stops after Task 3 and Task 6 for the owner to commit.

```tsx
import type { Metadata } from 'next';
import { notFound } from 'next/navigation';
import { ServiceDetail } from '@/components/services/service-detail';
import { getBranchesForService, getServiceBySlug, getServices } from '@/lib/content';

export const dynamicParams = false;

export function generateStaticParams() {
  return getServices().map((service) => ({ slug: service.slug }));
}

export async function generateMetadata(props: PageProps<'/services/[slug]'>): Promise<Metadata> {
  const { slug } = await props.params;
  const service = getServiceBySlug(slug);
  if (!service) return { title: 'Service not found' };
  return { title: service.name, description: service.shortDescription };
}

export default async function Page(props: PageProps<'/services/[slug]'>) {
  const { slug } = await props.params;
  const service = getServiceBySlug(slug);
  if (!service) notFound();

  const related = getServices().filter((item) => item.slug !== service.slug).slice(0, 3);

  return (
    <ServiceDetail
      service={service}
      branches={getBranchesForService(service.slug)}
      related={related}
    />
  );
}
```

```tsx
'use client';

import Image from 'next/image';
import { useState } from 'react';
import { Card } from '@/components/ui/card';
import type { Optometrist } from '@/lib/types';
import { cn } from '@/lib/utils';

type Person = { optometrist: Optometrist; branchNames: readonly string[] };
type BranchOption = { slug: string; name: string };

export function OptometristDirectory({
  people,
  branches,
}: {
  people: readonly Person[];
  branches: readonly BranchOption[];
}) {
  const [branchSlug, setBranchSlug] = useState<string | null>(null);

  const selected = branches.find((branch) => branch.slug === branchSlug);
  const shown = branchSlug
    ? people.filter(({ optometrist }) => optometrist.branchSlugs.includes(branchSlug))
    : people;

  return (
    <div>
      <div className="flex flex-wrap gap-2" role="group" aria-label="Filter by branch">
        {[{ slug: null, name: 'All branches' }, ...branches].map((option) => {
          const isSelected = option.slug === branchSlug;
          return (
            <button
              key={option.slug ?? 'all'}
              type="button"
              aria-pressed={isSelected}
              onClick={() => setBranchSlug(option.slug)}
              className={cn(
                'inline-flex min-h-11 items-center rounded-full border px-5 text-sm font-medium transition-colors duration-200 focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-primary',
                isSelected
                  ? 'border-transparent bg-primary text-primary-foreground'
                  : 'border-primary/30 text-primary hover:bg-secondary',
              )}
            >
              {option.name}
            </button>
          );
        })}
      </div>

      <p role="status" className="mt-4 text-sm text-muted-foreground">
        Showing {shown.length} optometrists{selected ? ` at ${selected.name}` : ''}
      </p>

      <ul className="mt-8 grid gap-6 sm:grid-cols-2 lg:grid-cols-3">
        {shown.map(({ optometrist, branchNames }) => (
          <li key={optometrist.slug}>
            <Card className="flex h-full flex-col gap-4 p-0">
              <Image
                src={optometrist.photo.src}
                alt={optometrist.photo.alt}
                width={optometrist.photo.width}
                height={optometrist.photo.height}
                className="aspect-4/5 w-full rounded-t-card object-cover"

                  {optometrist.name}, {optometrist.credentials}
                </h2>
```
